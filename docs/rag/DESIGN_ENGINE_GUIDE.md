# Guia del Design Engine (Studio) — Novamente Workspace

## Que es el Design Engine

El Design Engine es el generador de diseños con inteligencia artificial integrado en el workspace. Permite crear estampas y diseños para prendas usando lenguaje natural (prompts en texto). No hace falta saber disenar ni usar Photoshop.

El motor de IA usa **Gemini** (modelo Nano Banana 2) para generar los diseños y un modelo especializado para componer el mockup final sobre la prenda.

---

## Opciones de Generacion

### Estilos Artisticos

Hay mas de 37 estilos disponibles para darle una direccion visual al diseno. Ejemplos:

- Grunge / Punk / Streetwear
- Minimalista / Lineal / Geometrico
- Vintage / Retro / Old School
- Ilustracion / Cartoon / Anime
- Dark / Gothic / Metal
- Acuarela / Painterly / Artistico
- Tipografico / Lettering / Caligrafía
- Abstracto / Psicodelico / Surreal
- Naturaleza / Botanico / Animal
- Urbano / Graffiti / Pop Art

Cada estilo tiene una miniatura visual para ayudarte a elegir.

### Prendas Disponibles

| Prenda | Descripcion |
|--------|-------------|
| **Aura Oversize T-shirt** | Remera de corte oversize, cuello redondo |
| **Aldea Classic T-shirt** | Remera clasica, fit ajustado |
| **Astra Oversize Hoodie** | Hoodie/buzo amplio con capucha |
| **Lienzo** | Canvas para arte o decoracion (sin prenda) |

### Colores de Prenda

- Negro
- Blanco
- Crema (off-white)
- Gris

### Cara de la Prenda

- **Frente**: El diseno se estampa en el pecho o zona delantera
- **Espalda**: El diseno se estampa en la parte posterior

## Como Generar un Diseno

### Paso 1: Seleccionar estilo
Hacer click en el estilo que mejor represente la estetica que buscas. El estilo guia la IA en el tipo de trazo, composicion y paleta.

### Paso 2: Escribir el prompt
Describir el diseno que queres en el cuadro de texto. Ser especifico ayuda mucho.

**Ejemplos de prompts efectivos:**
- "Calavera con rosas rojas, estilo old school tattoo, en blanco y negro"
- "Montana nevada con luna llena, minimalista, solo lineas finas"
- "Texto 'Sin Limites' con lettering bold, estilo graffiti, degradado neon"

### Paso 3: Elegir prenda y configuracion
Seleccionar la prenda, el color y la cara (frente/espalda).

### Paso 4: Generar
Hacer click en **Generar**. El proceso tarda entre 15 y 45 segundos.

El resultado es un mockup con el diseno estampado sobre la prenda elegida.

## Funciones Avanzadas

### Adjuntar imagen de referencia
Podes subir una imagen propia para que la IA la use como referencia visual. Util para:
- Adaptar un logo al formato de estampa
- Reinterpretar un arte existente en otro estilo
- Usar una foto como punto de partida

### Esencia de Marca
Si activas el toggle **"Usar esencia de marca"**, la IA incorpora la descripcion de tu empresa al prompt automaticamente. Sirve para que los diseños tengan coherencia con tu identidad de marca.

### Historial de Sesiones
Cada conversacion con el Design Engine se guarda como una sesion. Podes:
- **Cambiar entre sesiones**: Ver disenos anteriores sin perderlos
- **Crear nueva sesion**: Para empezar un proyecto de diseno separado
- **Eliminar sesion**: Si ya no la necesitas

El historial persiste entre visitas al workspace.

## Mockup Automatico

Cuando la IA genera el diseno (estampa), automaticamente lo compone sobre la prenda seleccionada. El resultado es un mockup realista listo para usar en:
- Tu storefront de Novamente
- Redes sociales
- Presupuestos a clientes

---

## Publicar un Diseno al Storefront

Desde el Design Engine, podes publicar un mockup directamente como imagen principal o banner de tu storefront:
1. Seleccionar el mockup generado
2. Click en **Publicar como hero** o **Publicar como banner**
3. El storefront se actualiza automaticamente

## Consejos para Mejores Resultados

- **Se especifico**: "Aguila con alas abiertas, estilo woodcut, blanco sobre negro" funciona mejor que "aguila".
- **Mencioná colores**: La IA respeta mejor la paleta cuando la incluis en el prompt.
- **Usa el estilo correcto**: Elegir un estilo distante al resultado que buscas da resultados inconsistentes.
- **Iteraciones rapidas**: Si el primer resultado no convence, modificar el prompt y generar de nuevo. Las sesiones son rapidas.
- **Adjunta referencias**: Si tenes un arte que te gusta, subilo como referencia para orientar mejor la generacion.
- **Prompts en castellano**: El sistema esta optimizado para entender prompts en espanol argentino.
